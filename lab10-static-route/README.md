# ปฏิบัติการที่ 10 Static Route

รหัสนักศึกษา: **6710210-317**  
ชื่อ: **นายวีรชาติ แก้วขำ**

เอกสารที่กรอกครบทุก Task: [`L10-6710210-317-completed.docx`](L10-6710210-317-completed.docx)

ชุดคำสั่งสำหรับวางใน Cisco Packet Tracer อยู่ในโฟลเดอร์ [`configs/`](configs/).

## อุปกรณ์

| รายการ | รุ่น |
| --- | --- |
| Router | 2911 (Task 2–3 เพิ่มโมดูล **HWIC-2T**) |
| Switch | Switch-PT |
| PC | PC-PT |

วิธีใส่ HWIC-2T: เปิด Physical ของ Router → ปิดสวิตช์ไฟ → ลาก **HWIC-2T** ใส่ช่องว่าง → เปิดไฟอีกครั้ง จะได้พอร์ต `Serial0/3/0` และ `Serial0/3/1`

สาย Serial ด้านที่เป็น DCE ต้องใส่ `clock rate 64000` ไม่งั้น Protocol จะเป็น down

## Task 1 — Single Router

เครื่อง A, B, C, D ติดต่อกันได้ผ่าน R1 โดยไม่ต้องใช้ static route เพราะเป็นเครือข่ายที่ต่อตรง

```
                R1
         Gi0/0 /   \ Gi0/1
  192.168.10.0/24   192.168.20.0/24
         SW1           SW2
        /   \         /   \
       A     B       C     D
```

### Router

| Router | Interface | IP address | Subnet Mask |
| --- | --- | --- | --- |
| R1 | Gig0/0 | 192.168.10.1 | 255.255.255.0 |
| R1 | Gig0/1 | 192.168.20.1 | 255.255.255.0 |

### PC

| PC | IP address | Subnet Mask | Default Gateway |
| --- | --- | --- | --- |
| A | 192.168.10.2 | 255.255.255.0 | 192.168.10.1 |
| B | 192.168.10.3 | 255.255.255.0 | 192.168.10.1 |
| C | 192.168.20.2 | 255.255.255.0 | 192.168.20.1 |
| D | 192.168.20.3 | 255.255.255.0 | 192.168.20.1 |

คำสั่ง: `configs/task1-r1.txt`

ทดสอบจาก PC A:

- `ping 192.168.10.3` (B) TTL=128 เพราะอยู่ใน LAN เดียวกัน
- `ping 192.168.20.2` (C) และ `ping 192.168.20.3` (D) TTL=127 ผ่าน R1

## Task 2 — Two Routers

เครื่อง A, B, C ติดต่อกันได้ด้วย **static route** ข้าม serial `192.168.1.0/24`

```
     A                B                      C
     |                |                      |
  10.0/24          20.0/24                30.0/24
     |                |                      |
    R1 Gi0/0     R1 Gi0/1               R2 Gi0/0
     \                /                      |
      ------ R1 ------  Se0/3/0 = 1.1        |
                    Se0/3/0 ================= Se0/3/0 1.2  R2
                         192.168.1.0/24
```

### Router

| Router | Interface | IP address | Subnet Mask |
| --- | --- | --- | --- |
| R1 | Se0/3/0 | 192.168.1.1 | 255.255.255.0 |
| R1 | Gig0/0 | 192.168.10.1 | 255.255.255.0 |
| R1 | Gig0/1 | 192.168.20.1 | 255.255.255.0 |
| R2 | Se0/3/0 | 192.168.1.2 | 255.255.255.0 |
| R2 | Gig0/0 | 192.168.30.1 | 255.255.255.0 |

### Static route

| Router | Network | Subnet Mask | Next Hop |
| --- | --- | --- | --- |
| R1 | 192.168.30.0 | 255.255.255.0 | 192.168.1.2 |
| R2 | 192.168.10.0 | 255.255.255.0 | 192.168.1.1 |
| R2 | 192.168.20.0 | 255.255.255.0 | 192.168.1.1 |

### PC

| PC | IP address | Subnet Mask | Default Gateway |
| --- | --- | --- | --- |
| A | 192.168.10.2 | 255.255.255.0 | 192.168.10.1 |
| B | 192.168.20.2 | 255.255.255.0 | 192.168.20.1 |
| C | 192.168.30.2 | 255.255.255.0 | 192.168.30.1 |

คำสั่ง: `configs/task2-r1.txt`, `configs/task2-r2.txt`

`show ip route` ของ R1 จะมี `S 192.168.30.0/24 [1/0] via 192.168.1.2`

## Task 3 — Three Routers

เครื่อง A และ B ติดต่อกันได้ผ่าน R1 — R2 — R3

```
A -- 10.0/24 -- R1 -- 1.0/24 -- R2 -- 2.0/24 -- R3 -- 20.0/24 -- B
                  Se0/3/0         Se0/3/0
                                  Se0/3/1         Se0/3/1
```

### Router

| Router | Interface | IP address | Subnet Mask |
| --- | --- | --- | --- |
| R1 | Se0/3/0 | 192.168.1.1 | 255.255.255.0 |
| R1 | Gig0/0 | 192.168.10.1 | 255.255.255.0 |
| R2 | Se0/3/0 | 192.168.1.2 | 255.255.255.0 |
| R2 | Se0/3/1 | 192.168.2.1 | 255.255.255.0 |
| R3 | Se0/3/1 | 192.168.2.2 | 255.255.255.0 |
| R3 | Gig0/0 | 192.168.20.1 | 255.255.255.0 |

### Static route

| Router | Network | Subnet Mask | Next Hop |
| --- | --- | --- | --- |
| R1 | 192.168.20.0 | 255.255.255.0 | 192.168.1.2 |
| R2 | 192.168.10.0 | 255.255.255.0 | 192.168.1.1 |
| R2 | 192.168.20.0 | 255.255.255.0 | 192.168.2.2 |
| R3 | 192.168.10.0 | 255.255.255.0 | 192.168.2.1 |

### PC

| PC | IP address | Subnet Mask | Default Gateway |
| --- | --- | --- | --- |
| A | 192.168.10.2 | 255.255.255.0 | 192.168.10.1 |
| B | 192.168.20.2 | 255.255.255.0 | 192.168.20.1 |

คำสั่ง: `configs/task3-r1.txt`, `configs/task3-r2.txt`, `configs/task3-r3.txt`

ทดสอบจาก PC A:

```
ping 192.168.20.2
tracert 192.168.20.2
```

เส้นทางที่ถูกต้อง:

1. 192.168.10.1 (R1)
2. 192.168.1.2 (R2)
3. 192.168.2.2 (R3)
4. 192.168.20.2 (B)

## ลำดับทำใน Packet Tracer

1. วางอุปกรณ์ตามรูปในใบงาน
2. ปิดไฟ Router แล้วใส่ HWIC-2T (Task 2 และ Task 3)
3. เดินสาย: Copper Straight-Through ฝั่ง LAN, Serial DCE ฝั่ง WAN
4. ตั้ง IP / Gateway ของทุก PC ตามตาราง
5. วางคำสั่ง Router จากไฟล์ใน `configs/`
6. `ping` และ `tracert` จากแท็บ Desktop → Command Prompt ของ PC
7. คัดลอกผล `show ip interface brief` และ `show ip route` ใส่ใบงาน (ไฟล์ `.docx` ในโฟลเดอร์นี้กรอกไว้แล้ว)
